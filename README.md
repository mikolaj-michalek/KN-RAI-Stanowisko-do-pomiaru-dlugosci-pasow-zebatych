# KN-RAI-Stanowisko-do-pomiaru-dlugosci-pasow-zebatych
Projekt zakłada zaprojektowanie i wykonanie demonstracyjnego stanowiska pomiarowego do wyznaczania długości pasów zębatych. Firma Optibelt zapewnia wsparcie w postaci komponentów niezbędnych do budowy układu.

Pomiar długości pasa będzie opierał się na zliczaniu impulsów z enkodera, a następnie przeliczaniu ich na długość liniową pasa w milimetrach. Układ będzie uwzględniał wybrany profil pasa zębatego, tak aby liczba zębów odpowiadała właściwej długości nominalnej.
